# deterministic-neural-column

一个**纯神经元与突触**的工作记忆/序列架构，全部验收判据在 **6/6 个随机种子上通过**。

没有符号、没有闸门模块、没有状态机。只有：LIF 式阈值细胞、突触、除法归一化、
软边界赫布学习、每细胞权重守恒。

```
280 通道输入
  → 局部三维感觉栈（固定权重，权重阈值 θ≈0.98，约 12% 稀疏）
  → 拓扑投射到 L2/3（1024 细胞）
  → L2/3 ⇄ L5（1024 / 512，阈值规则；L5 的输入驱动做除法归一化）
  → M1 运动区（每个转移一个 280 细胞区块，赫布学习，初始权重为 0）
  → 输出被"听到"，经感觉栈重新编码
  → 回到 L2/3（大环闭环）
```

## 让它成立的八处修正

每一处都有实测对照，不修就会失败：

| # | 修正 | 不修时的实测后果 |
|---|---|---|
| 1 | 确定性而非随机脉冲递归 | 同一输入两次相关 **−0.01**（随机递归网络稳定放电率、稳定不了图案） |
| 2 | 局部/拓扑投射 | 随机投射把稀疏图案平均成均匀驱动，内容根本进不来 |
| 3 | 输入对比度归一化 | 硬阈值把 1.6 倍的密度差放大成 10 倍 |
| 4 | 运动区 = 280（复现输入本身） | 重建 2800 维感觉层在信息论上做不到，保真度卡在 0.6 |
| 5 | 分开运动通道（每转移一块） | 两个转移互相抹平，保真度退化到随机水平 **0.58** |
| 6 | 驱动电流的除法归一化 | 弱项目（70–76 个活跃细胞）在 L5 阶段归零 |
| 7 | 阈值预算随实际输入变化 | 撤掉输入后递推跨不过门槛，存活 3/6 |
| 8 | **呈现时自适应阈值（100–400 细胞）** | 弱项目死在 L5、最大集群吞掉之后每一步 |

第 8 条是最后一块：硬阈值下各项目的集群规模是**阶跃的**（实测 70 / 76 / 205 / 510 细胞），
所以按每个项目实际得到的活跃细胞数调阈值，把集群控制在 100–400 之间。
这不是 top-k（不选择细胞），也不改变稀疏化规则。

## 与参考工作的关系

感觉层的稀疏化规则来自 [local3d-similarity](https://github.com/leeR1ven/local3d-similarity)
（如果可见）：局部三维邻域 + 每个细胞用**自身权重预算**做阈值：

```
active_i  ⟺  score_i > θ · (|b_i| + Σ_j |w_ij|)
```

这比 top-k 好，而且不依赖全局排序。本仓库的实验表明，这条规则给出的稀疏态
在递归网络里也能稳定——前提是阈值预算**随实际存在的输入变化**（修正 7）。

## 文档

- [`SPEC.md`](SPEC.md) —— 结构约束、判据、最终配置、逐条实测
- [`RESULTS.md`](RESULTS.md) —— 全部实验记录，**包括大约三十轮的失败与误判**

`RESULTS.md` 里的负面结论仍然成立：在"随机连接 + 稀疏脉冲 + 一个兴奋群 + 一个抑制群
+ 局部赫布"这个模型族里，确实找不到稳定的分布式稀疏自持态（静默 / 饱和 / 一小撮细胞锁死）。
本仓库不是推翻那个结论，而是换掉了那个模型族。

## 已知限制

- 规模只到 1024 / 512 细胞，没有放大到十万级；
- "100–400 细胞"这个区间是工程上选定的，没有从第一原理推导；
- 只验证了 6 个随机种子，没有做更大范围的扫描；
- 语言输入用的是字符 n-gram 编码（`code/text_encoder.py`），不是真正的语言模型。
