# deterministic-neural-column — 图像识别（纯神经元版本）

固定权重的局部三维网络，加上运动输出。**没有卷积、没有反向传播、没有标签、没有 top-k、
没有把图片存在网络外面。**

## 结构

```
28×28 图像
   ↓
① 局部三维层（12544 个细胞，排列成 28×28×16 的三维体积）
     · 每个细胞接收"自己 + 3 个随机近邻"
       （dx, dy ∈ {−1,0,1}，dz ∈ {−2,…,+2}）
     · 权重固定随机，不训练
     · 激活规则：score > θ × (|bias| + Σ|w|)，
       每层一个 θ，标定到约 20% 的细胞激活
   ↓
② 运动细胞（10 个动作 × 每个动作 60 个细胞）
     · 每个运动细胞是一组权重，对应一种"做这个动作的方式"
     · 教学时：该动作还有空的细胞就存下当前模式；
       否则该动作里最相近的细胞朝当前模式小步移动
     · 判断时：不许给动作，概念活动驱动运动细胞，
       每个动作取它最相近的那个细胞，驱动最高的动作即答案
```

**整个网络里不存任何图片。唯一的记忆是突触权重。**

## 结果

**手写数字（MNIST，28×28），10000 张训练、1000 张留出（从未参与训练）：**

| 每个动作的运动细胞 | 留出准确率 |
|---|---|
| 1 | 0.764 |
| 30 | 0.943 |
| **60** | **0.951** |
| 120 | 0.951（训练 0.974，开始过拟合）|

**三个种子（每动作 60 个细胞）**：

| 种子 | 训练 | 留出 |
|---|---|---|
| 1 | 0.960 | 0.947 |
| 2 | 0.968 | 0.954 |
| 3 | 0.966 | 0.951 |
| **均值** | 0.965 | **0.951** |

**泛化到没见过的外观**：训练只给 −20°/−10°/0°/+10°/+20° 五个角度，测没给过的角度：

| 测试角度 | 类型 | 准确率 |
|---|---|---|
| −15° | 没见过的角度 | 0.907 |
| −5° | 没见过的角度 | 0.945 |
| +5° | 没见过的角度 | 0.915 |
| +15° | 没见过的角度 | 0.915 |
| 30° | 训练范围外 | 0.838 |
| 45° | 训练范围外 | 0.632 |

**大角度失败是正常的**：这种外观从未出现，也没有任何信息告诉过模型"转过的 8 和正的 8 是同一个"。

## 实测的激活分布

同一个数字的 300 张图（第 1 层 12544 个细胞）：

- **每次必亮的细胞：566 个**（占 4.5%）；
- 超过一半图亮的细胞：2436 个；
- 只在 10%–90% 的图里亮的"渐变区"：4612 个；
- 激活频率分位数（10/25/50/75/90%）：**0.01 / 0.05 / 0.24 / 0.59 / 0.81**；
- 不同图片的激活中心：y 14.0±0.2，x 13.9±0.2，**位置稳定**。

**即：一片稳定的核心 + 外围渐变的晕**，不是"固定的几个细胞代表一个概念"。

## 这个模型里**没有**什么

- ❌ **k 近邻（kNN）**：不在模型里。把训练图片存在网络外、来了新图就比对——那不是这个架构的一部分；
- ❌ **外部记忆数组**：没有；
- ❌ **卷积 / 反向传播 / 梯度**：没有；
- ❌ **top-k 稀疏化**：没有（稀疏性来自每个细胞自己的权重预算阈值）；
- ❌ **手工指定"哪些神经元代表哪个数字"**：没有；
- ❌ **额外的概念层 / 标签层**：没有。

## 文件

| 文件 | 作用 |
|---|---|
| `code/sensory.py` | 局部三维层的构造（细胞、近邻、固定权重、阈值激活） |
| `code/motor_multi.py` | **主模型**：图像 → 局部三维层 → 运动细胞（每动作 60 个）→ 答案 |
| `code/motor_answer.py` | 对照版本：每个动作只有一个运动细胞（0.764） |
| `code/motor_rotation.py` | 泛化测试：训练给一组角度，测没给过的角度 |
| `code/why_low.py` | 诊断：激活分布、同类/别类重叠、以及"运动读出的损失在哪里" |
| `code/one_digit.py` | 单个数字的细胞激活频率分布 |

运行：

```bash
python code/motor_multi.py 10000 1000 8 60      # 主模型
python code/motor_rotation.py 2000 400 6        # 泛化测试
python code/why_low.py                          # 诊断
```

## 已删除的内容（避免误解）

仓库里曾有一批实验脚本，它们**不属于这个架构**，已删除：

- 用 **kNN 作为读出**的评测（把训练图存在网络外，成绩不能归给这个模型）；
- 我自行添加的**概念层 / 标签层**（实测有害：把 0.764 压到 0.53）；
- **稠密全连接 + 纯赫布**的版本（所有细胞收敛到同一个平均值，0.13）；
- 各种**结构改动**实验（多通道、金字塔、不同分辨率、不同扇入、不同偏置、不同权重比例），
  结论是这些都没有提高；
- **外部记忆槽 / 慢学习率**实验（那部分记忆在数组里，不在网络里）。

保留的只有：局部三维层本身，以及**答案从运动输出出来**的那个模型。
