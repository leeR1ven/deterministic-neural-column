# deterministic-neural-column

**中文** | 一个用**纯神经元与突触**搭的工作记忆与序列模型：没有符号、没有查表、没有每个转移的专属单元。
本文档给出**当前**模型、**可复现**的结果，以及每条结果对应的命令与预期输出。

**English** | A deterministic, neuron-and-synapse-only model of working memory and sequence
generation. No symbols, no lookup tables, no per-transition units. This README lists the
current model, the results that are reproducible, and the exact command for each claim.

---

## 1. 这个项目在做什么

**任务**：给模型一串输入（词），它能

1. **记住**当前输入（撤掉输入后状态仍存在）；
2. 在记忆里**走向下一个**输入（序列生成，而不是查表）；
3. 用**动作**把「想到的东西」表达出来（肌肉组合与顺序），别人能读懂；
4. 也能**听懂**外部给的动作序列，并回以动作。

**输入**：词（字符 n-gram 编码，`code/text_encoder.py`）。
**输出**：一段肌肉激活序列（`16 块肌肉 × 5 个时间步`）。
**成功判据**：见第 4 节，每条都有命令和预期输出。

---

## 2. 当前模型（一张图）

```
词 → 稀疏码（1024 细胞，每词约 50 个细胞）
   → 概念层（256 细胞，仅用局部规则学习；概念细胞自己形成）
   → 前额叶小循环 L2/3 ⇄ L5（慢变量维持 + 抑制池）
   → 概念链预测下一个概念
   → 肌肉序列（16 肌肉 × 5 步）说出这个动作
   → 动作被"听到"（稀疏投射） → 回到概念层 → 再回答
```

**概念层怎么形成的**：每个细胞接收第一层 100 个输入；训练时响应最强的 3 个细胞把输入移向当前模式（赫布），
同时所有输入轻微衰减（竞争）。重复 300 轮后，**再测量**哪些细胞变成类别选择性的——概念细胞是长出来的，
不是事先规定的。

## 3. 可复现的结果

环境：Python 3.13 + torch（见 `requirements.txt`）；脚本用 CUDA（`DEV='cuda'`），CPU 未测试。

| # | 声明 | 命令 | 预期输出 |
|---|---|---|---|
| 1 | 6 个种子全部通过核心判据 | `python code/local_adapt2.py <seed>`（seed=0..5）| `MOTOR 1.00 1.00 \| DIST 0.13–0.31 \| HOLD 6/6` → `ALL CRITERIA PASS` |
| 2 | 同一命令两次逐字节相同 | 跑两次并比较输出 | `IDENTICAL OUTPUT: TRUE` |
| 3 | 三通路（只想/行动/本能/压制）6 种子通过 | `python code/pfc_blocks8.py <seed> 40` | `ALL CRITERIA PASS`，`ACT` 36–101，`INSTINCT 840`，`SUPPRESS` motor 0 |
| 4 | 工作记忆：12/12 保持、重叠 0.06、链条 7/7 | `python code/verify.py 0 1` | `hold 12/12 \| self 0.61 \| overlap 0.064 \| chain 7/7` |
| 5 | 概念细胞自己形成（37 个 vs 随机 0.1） | `python code/concept_emerge.py 0` | `37 of 256`，`shuffled-label chance: 0.1`，类别解码 40/40（留一法），**词解码 0/40** |
| 6 | 概念链 7/7 + 多概念 4/4 + 同结尾不同上文给不同答案 | `python code/concept_final3.py 0 0.24` | 链 `7/7`，多概念 `4/4`，`2 vs 4 : DIFFERENT` |
| 7 | 连续动作：粗略信号 → 连续轨迹；准备期不移动 | `python code/motor_dynamics2.py 0` | 终点最接近 0.734；准备期 `0.000`，放行后 `25.875` |

**关于第 1 行的链条，必须说清楚**：它是 `alp bet gam` 之后**不再前进**——6 个种子里，
4 个在 `bet↔gam` 之间循环，2 个固定在 `gam`。所以"序列"这一项成立的是**前三个词的顺序**，
不是更长的链。更长的链在 `scale_more8.py` / `concept_final3.py` 里另测（那两处是 7/7 和 15/15）。

**关于第 5 行**：概念层**只保留类别、丢掉了个体**（词解码 0/40）——这正是"概念"该做的事，
不是缺陷。早期的 40/40 是循环论证（把自身也算进去了），已修正。


> 第 3 节表格里的数值都可以通过这些命令重新得到。数字与文档不一致时，以命令输出为准，并请提 issue。

## 4. 哪些是神经元，哪些是实验者的代码

**这一节很重要**：本仓库的卖点是"纯神经元"，但为了做对照实验，脚本里有若干**实验者写的控制代码**。
诚实说明如下：

| 是神经元/突触的部分 | 是实验者代码的部分（脚本里已标注） |
|---|---|
| L2/3 ⇄ L5 的阈值放电、抑制池、慢变量维持 | `go` / `hold` 情境标志（`full_model.py:gate()`）——它们模拟"情境输入"，不是神经元 |
| 概念层的局部赫布学习 | 训练/测试的样本划分由脚本决定 |
| 肌肉协同（每概念 3 个时间步上的肌肉组合） | 肌肉协同的具体分配是脚本设定的（`SYN` 矩阵） |
| 动作输入走同一条稀疏投射 | 读出用最近模板比较（`listen()`），是一个显式的 argmax |
| 概念/词码的阈值化 | 阈值标定用二分法搜（`local_adapt2.py` 里的 `settle_item`），是外部控制器 |

**所以准确的说法是**：核心循环由细胞、突触、阈值与局部规则组成；外围的**情境标志、阈值标定、读出 argmax**
是实验者的脚手架。我们不声称"整个脚本没有一行控制代码"。

**另外**：`local_adapt2.py` / `pfc_blocks8.py` 的结果是**训练集上的**（同一批转移既训练又评估），
不是泛化结果。`two_stage6.py` 里有留出转移的对照，结论写在文件里。

## 6. 已知限制

- **规模**：核心循环 1024 / 512 细胞；概念层 256；最大测到 L2/3 4096、词表 160、链长 60。
- **训练集结果**：多数"完美"数字是训练集上的，泛化只在 `two_stage6.py` 里测过（会退化为记忆）。
- **阈值**：`100–400 细胞`这个区间是工程选定的，没有从第一原理推导。
- **种子数**：每次 6 个种子；没有做更大范围扫描。
- **语言**：字符 n-gram，不是真正的语言模型。
- **依赖**：`sensory.py` 的稀疏化规则参考 `local3d-similarity`，但**没有固定 commit、没有 vendored 副本**，
  README 旧版里"exactly 相同"的说法无法验证，已删除。

## 9. 术语

| 术语 | 意思 |
|---|---|
| L2/3 | 皮层第 2/3 层（本模型里是工作记忆的维持层）|
| L5 | 皮层第 5 层（本模型里是输出读出层）|
| M1 | 初级运动皮层（本模型里的运动区）|
| 稀疏码 | 只有少量细胞活跃的表示（本模型约 5% 的细胞）|
| 重叠 / Jaccard | 两个状态共享的细胞数 ÷ 并集细胞数；越低表示越可分 |
| 慢变量 | 由输入积分得到、衰减很慢的变量，用来"记住" |
