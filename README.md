# deterministic-neural-column

**中文** | 一个用**细胞、突触、阈值与局部规则**搭的神经网络。
它**没有目标**，所以它"此刻在想什么"由一件事决定：**哪一群细胞被激活得最多**。
本仓库测的是这个朴素的说法能走多远。
**English** | A deterministic, neuron-and-synapse network. It has no goal, so what it is
"thinking about" at any moment is decided by one thing: which population is activated
most strongly. This repository measures how far that simple statement goes.

> **这份文档只写有命令能验证的东西。** 每条声明对应一条命令和一个你可以自己跑出来的输出。
> 历史记录（含失败与撤回）在 [`RESULTS.md`](RESULTS.md)，实验设定在 [`SPEC.md`](SPEC.md)——
> 那两个文件是**实验日志**，不是当前状态。

## 1. 它实际做到了什么（一句话版）

| 能做到 | 证据 |
|---|---|
| 给一个词，**状态留下来**，而且不同的词状态不同 | 保持状态 128–384 个细胞（共 1024），自重叠 0.99，彼此重叠 0.12–0.33 |
| **重新给开头，能接上** | `alpha → zeta → delta` 之后重新给 `alpha`，状态回到 `alpha` |
| **外界信号累积够了，会顶掉当前想法** | 强度 × 数量的交叉点：0.10–0.20 再多也不变；0.35 到 6 个翻转；0.60 到 4 个翻转 |
| **概念自己形成**（不是规定的） | 37 / 256 个类别选择性细胞，随机对照 0.1 |
| **用肌肉组合说话，别人能听懂** | 7/7，三个种子 |
| 概念比词少 | 37 < 40 |

**没能做到**（详见第 3.5–3.9 节的撤回记录）：**泛化**（没有可信的留出测试）、
**有目的地维持一个想法**（它没有目标）、以及**一份能让陌生人精确重建的规范**。

**为什么"没有目的"这件事重要**：飘走、被新信息覆盖、不能原地恢复，
对一个没有目标的系统都是**正常行为**，不是缺陷。人能盯住一个想法，
是因为大脑已经泛化、**有目的**——这一环这个简单模型还没有。

## 2. 模型长什么样

```
词 → 稀疏码（1024 细胞，每词约 50 细胞）
   → 概念层（256 细胞，局部规则学习；概念细胞自己形成）
   → 前额叶小循环 L2/3 ⇄ L5（痕迹 + 抑制池；谁被驱动得多谁就是当前想法）
   → 预测下一个概念
   → 动作（16 肌肉 × 5 时间步）
   → 动作被重新编码 → 回到概念层 → 再回答
```

**重要：这张图是一个概念框图，不是某一个脚本的逐行实现。**
不同脚本实现的是其中不同部分，接口也不统一（有的输出 280 位词码，有的输出 80 通道动作，
`motor_dynamics2.py` 输出 2 维手的位置）。**没有任何一个脚本实现完整的这张图。**
各脚本的实现范围见第 5 节。

**概念层怎么形成的**：每个细胞接第一层 100 个输入；训练时响应最强的 3 个细胞把输入移向当前模式
（赫布），同时所有输入轻微衰减（竞争）；300 轮之后**再测量**哪些细胞变成类别选择性的。
概念细胞是长出来的，不是事先规定的。

  撤掉输入后保持状态是 **1024/1024 个细胞**、六项彼此重叠 **1.00**——那不是记忆，是全开。
  旧判据只看"平均激活 > 0.01"，所以永远能过。

  实测保持状态 **128–384 个细胞**、自重叠 **0.99–1.00**、彼此重叠 **0.12–0.33**。

  理由写在 `settle()` 的 docstring 里——留着会让人以为它在起作用。
- **第 1 行的链条只到第三个词**：`alp bet gam` 之后不再前进（4 个种子 `bet↔gam` 循环，2 个固定在 `gam`）。
- **第 7 行的"准备期不移动"是输出被闸门清零**，不是状态真的落在运动输出的零空间里。
  去掉那个清零分支，准备期会产生约 18.5 单位的"运动"。所以它是闸门，不是零空间。

## 3.5 留出测试：两个测试都失败了，所以目前没有泛化证据

**这一节是一个撤回。** 早先的版本在这里声称"概念层能泛化（7/8），序列层是查表"。
一个独立审计证明**这两个测试都不成立**，结论作废。保留这一节是为了记录错在哪。

命令：`python code/heldout.py <seed>`（seed 0/1/2）。

**A2 留出实例 —— 测试本身无效。**
概念层只用每类 4 个词训练，然后给第 5 个词（`catu`、`dogu`……）。它被认成自己类的比例是 7/8、6/8、8/8。

**但这证明不了概念**：审计实测，这些留出词与同类训练词的**输入码重叠 0.544**，与其它类只有 0.135。
**对输入码做最简单的最近邻（不训练、不用概念层）就能 8/8**——比概念层的 7/8 还好。
所以这个测试测的是"输入相似度"，不是"概念"。
（更正：早先这里写"概念层的阈值是在全部 40 个词上拟合的"，那是**错的**——
`heldout.py` 的阈值只用训练词拟合；这个理由已被审计推翻，但测试仍然无效，原因是上面那条。）

**A1 留出转移 —— 恒真，不含信息。**
`heldout.py` 里 `W_map[b] += 0.15 * (concept_cells[a] - W_map[b])` 把第 b 行**直接赋值成 a 的拷贝**。
留出的 `3→4` 没有写入，第 4 行恒为 0，于是所有得分都是 0，`argmax` 必然返回 0。
"训练转移 7/7、留出失败"两个数字都是结构决定的，不是测出来的。

**所以，本仓库目前没有任何可信的泛化证据。** 唯一做过、并且做得对的留出对照是
`python code/two_stage6.py 0`：它留出一个转移，**诚实地报告失败**（`memorisation only`）。

要继续往下走，需要重做的是：
1. 留出词的输入码**不能**简单到最近邻就能分类（例如用不同词干、只共享语义而不共享字母）；
2. 留出转移的映射必须是**学出来的**，不能在代码里把行赋值成前驱的拷贝；
3. 概念层的阈值只能在中训练词上拟合。

在这三件事做到之前，"概念层能泛化"和"序列层是查表"两句话都**不应引用**。

## 3.7 "保持"到底证明了什么（很弱，必须说清）

主演示现在打印 `hold is real: yes`，但一个独立审计证明**这个测试的效力很有限**。三条实测证据：

1. **把保持循环整段删掉，判据照样通过。** 审计把 10 步保持换成 `for _ in range(10): pass`，
   输出变成 `held sizes [128, 127, 192, 384, 256, 311] | self-overlap 1.00 | hold is real: yes | ALL CRITERIA PASS`。
   也就是说：**呈现状态本身就已经是不动点**，"撤掉输入后它还在"这件事是平凡的。
2. **每步改变的细胞数**：`alpha / gamma / delta / epsilon` 呈现时就已经是 64 细胞块组成的并集，
   自由运行后**一个细胞都不变**；`beta` 变 1 个、`zeta` 变 9 个，然后**剩下的 9 步里 0 变化**。
3. **保持状态的大小全是 64 的整数倍**（128/192/256/320/384），即由 16 个（L2/3 块, L5 块）配对
   整块拼出来。所以它更像"输入选中的一整块代码被记住"，而不是连续的群体动力学维持。

**因此本仓库能说的是**：呈现状态是稳定的、各项可区分的定点，**这在神经科学意义上算持续活动（persistent activity）**；
**不能说**的是"它能抵抗干扰"或"需要动力学来维持"——这两件事都没有测。

**要把它变成有意义的测试，至少需要**：
- 呈现 A 之后再呈现干扰项 B，看 A 是否还在（**已在 3.8 测过：A 存活 3/3**）；
- 对状态加扰动，看它是否回到原状态（吸引子性质）；
- 或者把保持判据改成"删掉保持循环就必须失败"——现在它不会。

这些没做之前，`hold is real: yes` 只应理解为"状态是稀疏且各项不同的定点"，不应理解为"工作记忆引擎"。

## 3.8 两个更严格的测试（`code/wm_tests.py`）

命令：`python code/wm_tests.py <seed>`。它复用主演示的矩阵**和逐项阈值**，再问两个问题。

**先做自检**：呈现 k、保持 10 步，状态还是 k 吗？→ **6/6**。（第一版脚本用了全局阈值，
得到 `alpha → zeta` 这种荒谬结果；那是脚本的错，不是模型。）

**测试 1 · 干扰**：先呈现 A，再呈现 B，然后保持。

| A | B | 最终状态 |
|---|---|---|
| alpha | beta | **alpha**（1.00）A 存活 |
| beta | alpha | **beta**（0.99）A 存活 |
| gamma | delta | **gamma**（0.75）A 存活 |

**A 在 3/3 情况下存活——B 覆盖不掉它。** 这既是好消息（抗干扰）也是限制：**状态无法被更新**，
它更像一个"锁存器"：**先到的输入决定状态，后来的输入改变不了它**。

**测试 2 · 扰动**：呈现后把已激活的 L5 细胞随机翻转，再看 10 步后是否回到原状态。

| 翻转比例 | 10 步后与原状态的重叠 |
|---|---|
| 5% | 0.68 |
| 20% | 0.25 |
| 50% | 0.23 |

**扰动不会被纠正。** 所以它不是"有吸引盆的吸引子"，只是一个**没有盆的稳定定点**。

**合起来的画像**：这个状态是**刚性定点**——存在、各项不同、能抵抗新输入，但**不能被更新、也不能从扰动中恢复**。
这解释了两件事：为什么主演示的链条走到第三个词就卡住（状态进不去新的定点），
以及为什么"保持"测试删掉循环也能过（它本来就不依赖动力学）。

（第一版扰动测试翻转的是 `x23`，但 `x23` 每步都由 `x5` 重算，所以翻转 `x23` 恒等于没扰动——
那次得到的"重叠 1.000"是脚本 bug，已修正。）

## 3.9 把慢变量真正接上：成功，但只成功了一半

**`code/wm_port.py`**（`python code/wm_port.py <seed> 150`）。它保留主演示的感觉栈输入，
把 `walk_rel2.py` 的痕迹回路接上去。完整报告见 `code/WM_PORT_REPORT.md`。

### 为什么我前三次搬运都失败

我把**稠密驱动**（`W_in @ s`）直接喂给回路。而 `walk_rel2` 喂的是**稀疏 0/1 码**。
两者的差别是致命的：

| | 稠密驱动 | 0/1 码 |
|---|---|---|
| 有输入 / 没输入的相对驱动 | 0.25 / 0.13（**1.9 倍**） | 1.00 / 0.03（**34 倍**） |
| 痕迹的对比度 `m_ref(on)/m_ref(off)` | 6.6 倍 | **18844 倍** |
| 自由运行 12 步后的归一化痕迹 | 0.361 | **0.844** |

**稠密驱动分不开"有输入"和"没输入"，所以痕迹形同虚设。** 修法只有一步：
**先用逐项标定的阈值把驱动二值化成 0/1 码**，再进回路。

### 结果（3 个种子）—— **注意：扰动那一行是错的，见下面的更正**

| 测点 | 主演示（定点） | wm_port 种子 0 | 种子 1 | 种子 2 |
|---|---|---|---|---|
| 自检（呈现后还是自己） | 6/6 | **6/6** | **6/6** | **6/6** |
| 扰动 5% / 20% / 50% | 0.68 / 0.25 / 0.23 | 0.84 / 0.82 / 0.81 | 0.78 / 0.77 / 0.71 | 0.81 / 0.77 / 0.76 |
| 干扰（A 之后来 B） | A 存活 3/3 | **B 赢 30/30** | B 赢 30/30 | B 赢 30/30 |
| 删掉痕迹（KAPPA=0） | — | held 0 个细胞 | 同 | 同 |

### 更正：扰动那一行不是"恢复"

第五次审计指出，`wm_port.py` **自己在同一行打印了"不扰动时"的漂移**：
种子 0 是 **0.847**，种子 1 是 **0.783**，种子 2 是 **0.817**。
而所谓"扰动后"的数字是 0.836 / 0.821 / 0.806（种子 0）——**等于或低于什么都不做**。

也就是说：**那个 0.84 不是"被扰动后回来了"，而是"这个状态本来就在慢慢漂"。**
而且扰动翻转的是 `x23`，一个由痕迹重算出来的派生变量；真正承载记忆的是痕迹 `m`。
直接扰动痕迹（把 5/20/50% 的活跃痕迹清零）得到的是 **0.844 / 0.761 / 0.501**，
并且 50% 时远差于声称的 0.81。

**所以"扰动恢复"这一条作废。** 剩下的有效结论只有两条：

1. **自检 6/6 是"存储检查"**——模板就是注入的码，呈现又精确复现它（审计实测 `TEMPL == CUE_CODES`）。
   删掉保持步骤也能 6/6。**它证明的是"码被存住了"，不是"工作记忆"。**
2. **干扰从"A 存活"变成"B 赢 30/30"**——这一条是真的，而且说明状态现在**可以被更新**了；
   代价是**不再抗干扰**。这是交换。

还有一条实现细节必须写出来：那个 **18844 倍的痕迹对比度，来自 `clamp(min=1e-6)` 这个硬编码下限**
（所有输入外的细胞 `m_ref` 都被夹到 1e-6）。把它去掉，保持状态变成 394–424 个细胞、自检 1/6。
**所以这个机制依赖一个硬编码常量，而文档里没有。**

### 还没解决的

- **保持会漏**：156 → 146 → 37 个细胞（自由运行 0/10/30 步）。原因是抑制比 `walk_rel2` 强
  （稠密码让抑制池有 62–97 个细胞活动，原版只有 33），不是 `TAU` 的问题。
- **一个旋钮摆不平两件事**：抑制增益调到 0.5 时保持完全稳定，但干扰变成混合态。
  而且那种情况下"扰动 1.00"也是**什么都不做的值**（审计实测每一行都是 1.000）。

**所以诚实的小结是：慢变量的移植让状态"可被更新"了（干扰方向反转），
但没有证明"扰动会恢复"（那一条是漂移的假象），而且它依赖一个未写入文档的硬编码下限。**

## 3.10 换个问法：它能做什么（而不是它做不到什么）

前面几节有一处测量标准的问题：我拿"有目的的记忆"去要求一个**没有目的**的模型，然后把它达不到的地方记成缺陷。
实际上，飘走、被新信息覆盖、不能原位恢复，对一个没有目标的系统都是**正常行为**。
所以这一节改问：**它实际能做什么？**（`code/wm_behavior.py`，`python code/wm_behavior.py <seed>`）

### 重新告诉它开头，能接上吗 —— 能

```
先走一段：alpha → zeta → alpha
中途给 delta：状态变成 delta
再把 alpha 给它：状态回到 alpha     ← 能重新接上
```

**"重新给开头就能想起来"这条是成立的。** 这正是设计者说的那种"想起"：靠重新激活，不是靠原地稳住。

### 给"盯住"信号，能挡住新信息吗 —— 在这个版本里挡不挡都一样

| hold_gain（1=不抑制，0=完全挡住新输入） | 原来的项目存活 |
|---|---|
| 1.00 | 2/2 |
| 0.60 | 2/2 |
| 0.30 | 2/2 |
| 0.00 | 2/2 |

**定点版本本来就不理新输入**，所以"抑制"这个旋钮对它没有作用。

### 两种模式，不是两个缺陷

| 版本 | 行为 | 像什么 |
|---|---|---|
| 定点版 `local_adapt2.py` | 新信息盖不掉旧的 | **专注**：盯住一个想法，忽略外界 |
| 痕迹版 `wm_port.py` | 新信息会覆盖旧的 | **开放注意**：随时被新信息改写 |

**两种都是正常行为。** 没有目标，"该专注还是该开放"这个问题本身没有答案——
这正对应设计者指出的：人能盯住一件事，是因为大脑已经泛化、**有目的**，而这个简单模型没有目的。

## 3.11 外界信号要到多少才改变思考 —— 设计者的预测成立

设计者的判断：**外界无关信号少时影响不了模型在想什么；信号多到一定程度，就会改变它，
因为外界激活的神经元变成了主要上下文。**

测试（`code/wm_competition.py`）：先让它想着 `alpha`，然后同时给它 k 个干扰词，
每个干扰词的强度乘 `alpha`，再让它稳定，最后看状态最像谁。

```
每个信号强度 \ 信号数量 |  1  |  2  |  4  |  6  |  8
        0.10            |  A  |  A  |  A  |  A  |  A     ← 弱信号：再多也不影响
        0.20            |  A  |  A  |  A  |  A  |  A
        0.35            |  A  |  A  |  A  | zet | zet    ← 6 个才翻转
        0.60            |  A  |  A  | del | del | del    ← 4 个就翻转
```

（A 表示"仍然想着 alpha"。）

**存在一个清晰的交叉点**：干扰的**强度 × 数量**累积到临界值之前，想法不受影响；
过了临界值，想法被顶掉。**这正是设计者说的机制——外界激活的神经元一旦成为主要上下文，
它就成为新的想法。**

两个附带的结果也有意义：

- **"加和"时一个干扰就能顶掉**（因为那个干扰本身就不弱），**"把总量固定、只增加细胞数"时反而没影响**
  （干扰被摊薄，没有细胞能过阈值）。所以决定性的量不是总强度，而是**有多少细胞被外界驱动到阈值以上**。
- 翻转后稳定在 `delta` 或 `zeta` 而不是随机的某个词，说明它落到了**某一个**干扰项的定点上，
  不是变成一团噪声。

## 3.12 泛化：一个测试，但测试设计本身存疑（结论暂不采用）

> **状态：暂停。** 这一节记录了一次泛化测试，但**设计者认为测试方法有问题**，
> 所以下面的结论**不作为本仓库的结论**，只作为"这次测法和它的数字"留档。
> 等设计者给出新的测试方法后再测。

**什么算泛化？** 这个测试（`code/generalize.py`）试图把这个问题问清楚。

设计：三个类别、每类 5 个词（同类共享词干）。规则是"任何一类的词出现，下一个词都是该类固定的那个词"。
**每类的第 5 个词完全不参与训练。** 测它能不能对上。

```
留出词（共享词干，比如 catu）         -> 3/3 对
对照 A：字母打乱（catu -> utca）      -> 3/3 对      ← 对照无效
对照 A2：完全不相干的词（zzq）        -> 1/3
对照 B：查表法                        -> 对留出词无从作答（12 条记录里没有它们）
```

**两个很关键的读数**：

1. **留出词 vs 同类的码重叠 0.18，vs 其它类 0.01**——所以它和同类"长得像"。
2. **字母打乱之后仍然 3/3**——这说明打乱**没有破坏字符组合**（n-gram 还在），
   所以那个对照是无效的，按事先定的规则，第一个 3/3 不能单独作数。
   **换成完全不相干的词，立刻掉到 1/3。**

**这次测试的过程记录（不作为结论）**：

> 留出词和训练词只差一个字母（`catu` vs `cata`），所以"泛化"可能只是输入相似；
> 而用来排除这一点的对照 A（字母打乱）**本身无效**（打乱不破坏 n-gram）；
> 更强的对照 A2 得到了 1/3，但这只有 3 个样本，统计上不足以支撑一个关于"模型能不能泛化"的判断。
>
> **所以这次测试既没有证明它能泛化，也没有证明它不能。** 结论待新的测试方法。

## 3.6 独立复刻：架构能被重建，但数字不能被重建

一个完全不知道本项目的智能体，**只看 SPEC.md / README.md / RESULTS.md，不许看 `code/`**，
从零写了一份 numpy 实现（`replication/`，附 663 行报告）。
这是本仓库最有价值的一次检验，结论有两半。

**好的一半：核心行为被独立复现了，而且有几项比原实现更好。**

| 行为 | 复刻者的实测 |
|---|---|
| 稀疏词码 | 69 细胞 / 1024，12 词两两 Jaccard **0.011** |
| 贴近随机码下界 | 160 词：**0.034 vs 下界 0.033（1.02×）** |
| 工作记忆（撤输入后） | 18–50 细胞存活，自相似 **0.58**，身份 **12/12**，两两 **0.000** |
| 链条 | 12 词和 36 词都是 **12/12**（本仓库是 7/7）|
| 概念细胞自己形成 | **34–36 / 256**，对照 0–5；训练前为 0 |
| 双向肌肉语言 | **8/8 说对、8/8 答对，3 个种子** |
| 两词上下文 | **6/6 读出、3/3 对比成立** |
| 三通路 | think 0、act **27 且匹配 1.000**、instinct 840、suppress 0 + BG 128 |
| 确定性 | 两次运行 SHA-256 相同 |

**注意"工作记忆"那一行**：复刻者在 `tau=4000`、`N23=4000` 的设置下得到 18–50 个细胞的存活状态、自相似 0.58；
本仓库 `local_adapt2.py` 现在是 128–384 个细胞、自相似 0.99。**但两者测的都是"呈现状态是不是不动点"**——
见第 3.7 节：把保持循环整段删掉，本仓库的判据照样通过，所以这个测试不足以证明"维持"。

**不好的一半：报告的精确数字无法从文字重建。**

复刻者列了 48 处欠定义，最关键的是：

1. **τ=400 没有单位、没有更新式**。他按 400 步算，状态在 1 秒前就死了；把 τ 调到 4000 才能通过。
   **一个数字就决定 E1 通过与否，而那个数字在文档里没有单位和方程。**
2. **阈值（0.17 / 0.24 / 0.30）是相对于一个未定义的预算的绝对值**，L5 扇入 K 从未给出。
3. **慢变量、`W_m` 的学习式、概念层的更新式都只有名字，没有公式。**
4. **"重叠/保真度"从未定义**——0.58 这个"随机水平"既不是 Jaccard（13% 密度下应为 0.0695）、
   也不是余弦（0.13），所以 0.58→1.00 这个头条数字无法核对。
5. **"响应"在概念判据里没有定义**，所以 37/256 不是一个可检验的预言。

**被复刻证伪的声明**（已在本文档更正）：

- **"容量律 m·f ≲ 2"**：复刻者的共享赫布映射在 **m·f = 20** 时仍 80/80，20 个细胞的码也 80/80。
  这条"律"不是所述机制的必然结果，只是原实现的一个经验观察。**已降级为观察，不再称为律。**
- **"概念两两重叠 0.000"**：那是**严格概念细胞**（每类 3–6 个）之间的关系，它们按构造就是不相交的；
  如果用"5 个词码的并集"（约 220 个细胞）当概念码，相互重叠是 **0.092**，不可能是 0。
- **"动作重叠 0.050"**：复刻者测到 0.014（最大值 0.20 与原文一致）。

**复刻者的判词**：*"一个称职的陌生人能重建出**一个**具备这些行为的模型，但无法知道它是不是**那个**模型，
也无法复现报告的数字，因为若干指标没有定义。这是一份好的实验日志，一份差的规格说明。"*

**对作者的要求**（下一步该做的）：

1. 给出**唯一一份**规范配置：慢变量的更新式与 τ 的**步数单位**、活动阈值的绝对单位、
   L5 阈值参照的预算、读出延迟、重置策略，以及"唯一的"输出宽度；
2. 把三条学习规则写成公式；
3. 定义所有指标（重叠、匹配 > 0.5、响应、p < 0.01），给出呈现时长、种子列表、训练/测试划分，
   并提交一份参考输出供 diff。

## 4. 哪些是神经元，哪些是实验者的代码

| 神经元/突触 | 实验者代码 |
|---|---|
| L2/3 ⇄ L5 的阈值放电、抑制池、慢变量 | `go`/`hold` 情境标志（`full_model.py` 的 `gate()`）|
| 概念层的局部赫布 + 竞争衰减 | **top-k 补足**：`local_adapt2.py` 在 L5 集群不足 24 个细胞时用 `T.topk` 补 |
| 动作由稀疏投射"听到" | **监督目标**：运动映射用脚本给的目标图案训练，并对其它区块做反赫布压制 |
| | **每项增益二分标定**（把码长统一到 70 个细胞）|
| | **读出 argmax**（`listen()`、`which()`）|
| | **每转移一块 280 细胞运动区块**（`local_adapt2.py` / `pfc_blocks8.py`）|

**所以准确的说法是**：核心循环由细胞、突触、阈值与局部规则组成；外围有相当多的实验者脚手架。
**"每个转移一块专属单元"在概念级模型（`concept_final3.py`）里没有，但在 `local_adapt2.py` 里明确存在**——
两者是不同的模型，不要混为一谈。

另外，`pfc_blocks8.py` 的四个场景里，**有三个是被常量保证的**：
"只想"用的是没有运动区块的抑制项（所以运动必为 0）；"本能"的驱动 6.0 远高于阈值 2.6（所以 840 个运动细胞必全亮）；
"压制"减去 6.0 的基底节抑制。只有"行动"是学出来的。这些是电路自检，不是三通路的证据。

## 6. 已知限制

- **训练集结果**：第 3 节第 1/3/4/6 行都是训练集上的。**目前没有任何可信的泛化证据**：
  第 3.5 节的两个留出测试都被证明无效（一个被测对象太简单、一个是恒真），
  唯一做对了的留出对照是 `two_stage6.py`，它的结论是"只会记忆"。
- **规模**：核心循环 1024/512；概念层 256；最大测到 L2/3 4096、词表 160、链长 60。
  这是 `motor_concept5.py` 的结果（`python code/motor_concept5.py 0 160 60 70 4096 4096` → `chain 59/59`）。
  **`scale_more8.py` 做不到这个规模**：它的输出层固定 280 通道，按仓库早先那条“容量”经验式（现在只当观察，不是律）估算需要约 2065 通道，实测只有 3/59。
- **阈值区间 100–400 细胞**是工程选定的，没有推导。
- **种子数**：每次 6 个，没有更大范围扫描。
- **语言**：字符 n-gram，不是语言模型。
- **依赖**：稀疏化规则参考 `local3d-similarity`，但**没有固定 commit、没有 vendored 副本**，
  所以"与参考实现完全一致"这句话无法验证。
- **未完成**：`pfc_blocks8.py` 里没有"前额叶 → 感觉区"和"前额叶 → 基底节"的投射；
  第 2 节的框图里那两条通路在本仓库中**没有被实现**。
