# deterministic-neural-column — 图像识别（局部三维层 + 运动输出）

固定权重的局部三维网络，前面接图像，后面接运动输出。没有卷积、没有反向传播、没有 top-k、
没有隐藏层。

**这份说明经过一次独立复现（另一个人/智能体，只有仓库、没有对话记录），
下面的数字和说法都是复现后的版本，与最初的草稿不同。**

## 结构

```
28×28 图像
   ↓
① 局部三维层（12544 个细胞，28×28×16）
     · 每个细胞：自己×1.0 + 3 个随机近邻×0.005–0.01 + bias
     · 权重固定随机，不训练
     · 激活：score > θ × (|bias| + Σ|w|)，θ 标定到约 20% 激活
   ↓
② 运动细胞（10 个动作 × 每个动作 60 个细胞，共 600 个）
     · 每个运动细胞是一组权重（12544 维），初始为空
     · 教学：该动作还有空细胞就存入当前模式；否则同动作中最相近的细胞小步移向当前模式
     · 判断：每个动作取它与该动作所有细胞的最大余弦相似度，最高的动作为答案
```

## 必须说清楚的一件事：它其实是一个最近邻分类器

复现时逐行检查代码得到的结论，我接受：

- 运动细胞的权重**就是存下来的模式**（600 × 12544 浮点数，约 30 MB，
  和 10000 张 28×28 原图的像素数同量级）；
- 判断过程是"拿当前模式与这 600 个模式求余弦、每类取最大、再取最高的类"——
  **这就是 1 近邻（k=1），带 600 个原型、每类 60 个**；
- 60 个原型由 LVQ 式的小步更新得到（有监督：更新时用了标签）。

所以"不存图片、没有 kNN"这个说法**在机制上是不成立的**，
只有在"不存原始 PNG、模式放在权重矩阵里"这个意义上勉强成立。**这一条已改。**

## 局部三维层的作用很小

复现时量到：

- 每个细胞的自身权重 1.0，3 个邻居加起来只有 **0.0225**；
- **去掉邻居（只看自己）只改变 0.17% 的激活**（99.83% 的激活模式完全一样）；
- 第 1 层模式与原始像素的余弦相似度相关 **r = 0.965**。

**换句话说，这一层基本等于"逐像素阈值化"，它没有做额外的计算。**

## 结果与基线（同一 10000/1000 划分）

| 方法 | 留出准确率 |
|---|---|
| 原始像素 1-NN | 0.954 |
| 原始像素 5-NN | **0.959** |
| 第 1 层模式 1-NN | 0.950 |
| 第 1 层模式 5-NN | **0.961** |
| 本模型，每动作 60 个原型 | 0.948 |
| **本模型，每动作 150 个原型** | **0.953**（三种子 0.957 / 0.951 / 0.951）|
| 本模型，每动作 300 个原型 | 0.939（过拟合）|
| 每类一个均值原型 | 0.824 |

**本模型没有超过"原始像素 5-NN"（0.959），也没有超过"第 1 层模式 5-NN"（0.961）。**
它最好的一次优化（原型从 60 增到 150）提高 0.5 个点，仍然差 0.6 个点。

## 优化尝试：让这一层真的做局部计算 —— 失败

复现指出近邻权重太小（三个近邻合计 0.0225），所以我把它调大，看这层能不能做出有用的局部计算：

| 近邻权重 alpha | 模型（600 原型） | 层模式 5-NN | 原始像素 5-NN |
|---|---|---|---|
| **0.01（几乎无近邻）** | **0.951** | **0.961** | 0.959 |
| 0.30 | 0.947 | 0.959 | 0.959 |
| 1.00 | 0.944 | 0.956 | 0.959 |
| 3.00 | 0.947 | 0.957 | 0.959 |

**调大近邻权重反而更差。这一层最优的状态就是"什么都不做"（等价于逐像素阈值）。**
局部平均会丢信息——这是这个结构的上限所在，不是参数没调好。

## 激活分布（全细胞口径，不是只算激活过的）

同一个数字的 300 张图、12544 个细胞：

- **37%（4664 个）细胞从不激活**；
- 全细胞激活频率分位数（10/25/50/75/90%）：**0 / 0 / 0.033 / 0.35 / 0.72**；
- "每次必亮"的 566 个细胞里，**536 个（94.7%）是 bias 超过阈值的死单元**——
  在纯黑图上就亮，对任何数字都亮；
- **位置稳定（y 14.0±0.2, x 13.9±0.2）只是 MNIST 已经居中**：原始像素的中心是 14.00±0.28 / 13.99±0.29，
  和模型一样。

最初说明里写的"分位数 0.01/0.05/0.24/0.59/0.81"是**只在激活过的细胞上算的**，
属于选择性呈现，已改。

## 已经修掉的 bug

**空细胞填充**：原代码让同一动作在一个 batch 里的所有样本选**同一个**空细胞，
导致第 1 轮每个动作只填约 40/60 个细胞，且同一命令重跑结果不一致。
修复后逐个样本分配不同的空细胞，同一 seed 两次运行逐位一致。

修复影响：60 细胞三种子均值 0.951 → **0.948**；M=30 从 0.934 → 0.955（波动属正常）；
早期 epoch 从 0.85 → 0.93。

## 运动区按设计者的描述重做：和视觉区同样的结构

设计者的要求：**运动区应该和视觉区、听觉区用完全相同的神经网络**；前额叶经大循环把信号送到
**运动区表层**（表层结构和视觉输入层一样）；激活特定区域就等于做了特定动作，动作代表数字。

实现（`code/motor_area.py`）：视觉区 28×28×16（原样）→ 前额叶模式经学出来的突触送到运动区表层
（10×10）→ 运动区自己也是一层同样的局部三维堆栈（10×10×16）→ **哪个区域（行）最活跃就是哪个动作**。

### 调通过程中修掉的两个 bug

| bug | 现象 | 修法 |
|---|---|---|
| 相似度只除以了突触行长度，没除以模式长度 | 表层 **100% 细胞激活**，无法判断 | 两边都归一化（余弦） |
| 运动区自己的堆栈从未标定阈值（默认 θ=0.9） | 运动区输出 **0% 激活** | 像其他区一样标定到 20% |

### 结果

| 运动表层每个细胞接多少输入 | 留出准确率 |
|---|---|
| 50 | 0.512 |
| 200 | 0.681 |
| **800** | **0.708–0.725** |
| 1200 | 0.690 |
| 2000 | 0.652 |
| 3200 | 0.616 |
| 全部 12544 | 0.580 |

**最佳是每个运动细胞接 800 个输入（约 6%），留出 0.71。**

**区域内加竞争**（`code/motor_area2.py`：每个动作是一块 4×40 的区域，区域内只有最像的几个细胞学习）
结果是 0.64–0.68，**没有更好**。

### 这说明什么

- **0.71 是"运动区做成和视觉区同样结构"这个设计目前的真实水平**；
- 之前那个 0.95，是靠让每个运动细胞**存下整张 12544 维的模式**（每动作 150 个）做到的——
  也就是复现时指出的"最近邻记忆"；
- 一旦每个运动细胞只能看一部分输入（像真正的表层那样），准确率就回到 0.71。

**所以：把运动区做成真正的神经网络，代价是从 0.95 降到 0.71；那 24 个点来自"每个细胞能记住一整张图"。**

### 按设计者描述的运动区，完整数字

| 链路 | 留出准确率 |
|---|---|
| 视觉区 → 运动区表层 → 运动区堆栈 → 区域 = 动作 | **0.71** |
| 视觉区 → 150 个整模式/动作 → 余弦取最大 | 0.95 |
| 原始像素 5-NN | 0.959 |

## 更正：我一直在偷偷用 top-k

设计者指出"不要用 top-k，而是通过权重调整保证稀疏激活"与"阈值化"不是一回事。**他是对的，我犯了错。**

区别是：

| | 做法 | 本质 |
|---|---|---|
| **设计者要求的** | θ 固定，每个细胞按**自己的权重预算**判断是否发射 | 稀疏来自**权重结构**：每个细胞的预算不同，所以同一个 θ 下有的容易发射、有的不容易 |
| **我做的** | 用二分法把 θ **调到刚好 20% 细胞激活** | **按比例截断**——这就是 top-k，只是用 θ 而不是排序实现的 |

**"把 θ 调到某个激活比例" = top-k 的另一种写法。** 我在每一次实验里都这么做了。

### 改正：θ 固定、不标定

`code/fixed_theta.py`，视觉区 12544 个细胞，θ 是常数：

| 固定 θ | 激活比例（平均 / 最低 / 最高，逐图变化） | 留出准确率 |
|---|---|---|
| **0.6** | **14.1% / 3.0% / 35.7%** | **0.950** |
| 0.9 | 9.4% / 0.8% / 31.9% | 0.931 |
| 1.0 | 0%（全静默） | 0.111 |
| 1.2 | 0%（全静默） | 0.111 |

**三条结论**：

1. **激活比例确实由权重决定**：θ=0.6 时同一批图里，有的图只激活 3%，有的激活 35.7%——没有任何截断；
2. **准确率 0.950，和"标定到 20%"的 0.951 一样**——**校准是多余的**；
3. **θ ≥ 1.0 就全静默**，因为每个细胞的自身权重是 1.0，分数超不过 1.0×预算。

**所以从今以后的所有结果都不标定 θ。**

## 多看几眼，运动区累积后再坍缩：确实提高（+13 点）

设计者的判断：多看看、让运动区的活动累积起来再坍缩，准确率应该更高。**这个判断被证实了。**

做法（`code/glances_collapse.py`，**所有 θ 固定、不标定**）：

```
每一眼：图平移一点（眼动）→ 视觉区（θ=0.6 固定）→ 前额叶模式
      → 运动区表层（θ=0.5 固定，16% 激活，用权重预算规则）
      → 运动区自己的局部三维层
      → 每个区域的活动量（z 和 y 方向求和）
坍缩：把各眼的活动量**累加**，最后才由活动最多的区域决定
```

**结果（10000 训练 / 1000 留出）**：

| 注视次数 | 1 | 2 | 3 | **4** | 5 | 6 | 7 | 8 | 9 |
|---|---|---|---|---|---|---|---|---|---|
| 累积后 | 0.469 | 0.477 | 0.482 | **0.500** | 0.494 | 0.491 | 0.477 | 0.470 | 0.467 |

| 对照 | 准确率 |
|---|---|
| **只看最后一眼、不做累积** | **0.371** |
| 4 眼累积 | **0.500** |

**+13 个百分点**——累积是有效的，不是心理作用。

**超过 4 眼之后下降**，原因是位移量越往后越大（±2 像素），数字被挪得太远，反而看不全。
所以注视次数有个最优点，不是越多越好。

**注意**：这里的绝对水平（0.50）比之前那些 0.79/0.95 低，因为那些数字用了"把 θ 标定到固定比例"，
也就是变相 top-k。**在不标定 θ 的前提下，0.50 是这条链路的实际水平。**
